# Anuththara Teacher — English Classes 2026
React + Vite + Tailwind v4. Run: `npm install && npm run dev`. Build: `npm run build`.
Edit `src/data.js` (contact, branches, timetable) and `src/i18n.js` (text).
## Deploy to Vercel
1. Push this folder to GitHub. 2. vercel.com → Add New Project → import the repo.
3. Framework: Vite (auto). Build `npm run build`, output `dist`. 4. Deploy.
